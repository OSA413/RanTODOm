# Randomized TODO List

Have a lot of things to do but don't know where to start?

I've got you covered!

https://osa413.github.io/RanTODOm/

---------------------

This program helps selecting random things to do (from the list that you fill). This should help you when you don't know what things to do and you have a lot of them. For example, you can use it for your hobby things.

It should help people with ADHD, VAST and/or procrastination.
